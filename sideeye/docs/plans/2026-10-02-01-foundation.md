# Plan 01 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffolded Next.js (JS) app with brand theme, Postgres + Prisma models, and tested pricing math.

**Architecture:** Manual minimal scaffold (folder already holds `docs/`), Tailwind brand tokens, Prisma schema exactly per spec §7, pure-JS money/pricing libs covered by `bun test`.

**Tech Stack:** Next.js App Router (JS), Bun, Tailwind CSS, Prisma + Postgres 16, zod.

**Spec:** `sideeye/docs/2026-10-02-sideeye-design.md` (§2, §7, §10, §12 step 1–3)

## Global Constraints

- JavaScript only, no TypeScript. Bun runtime.
- Money as integer paise everywhere; server recomputes totals.
- Shipping: flat Rs.49 (`SHIPPING_FLAT_PAISE = 4900`), free above Rs.999 (`FREE_SHIPPING_ABOVE_PAISE = 99900`), one config constant.
- Categories seeded exactly: Necklace, Earring, Anklet, Ring, Bracelet, Arm Bracelet.
- Product `vibes` multi-tag labels exactly: Eye Special, Funky, Queen, Slay, Baddie.
- DATABASE_URL: `postgresql://postgres:postgres@localhost:5432/postgres`.
- Red primary ~#E63946 + white; mobile-first 360px.

## Review Focus

- Prices render from paise without float drift (e.g. 19999 → "₹199.99", never "₹199.989999").
- Over-100% or stacked discounts can never drive a total below zero.
- Expired/inactive coupons are rejected even if the code string matches.
- Free-shipping threshold is boundary-exact (99899 pays shipping, 99900 does not).
- Migration is re-runnable and seed is idempotent (no duplicate categories on second run).
